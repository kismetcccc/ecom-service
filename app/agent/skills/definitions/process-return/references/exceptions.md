# 退款例外处理

| 情况 | 处理边界 |
| --- | --- |
| 多个订单、没有明确订单 | 只补问订单，不批量提交 |
| 换货、部分退款、部分商品退货 | 当前自助工具只支持整单退款申请，转人工，不转换用户诉求 |
| 退款处理中、已退款 | 不重复预览；查询已有申请或引导提供编号 |
| RAG/Wiki 不可用 | 不生成具体政策结论；聊天核验停在受阻状态。独立订单面板只能做系统初步资格检查 |
| 政策片段是演示资料 | 标记演示来源，不把它作为真实售后承诺 |
| 资格不通过 | 展示待人工核实，不绕过工具限制 |
| 预览过期、订单版本变化 | 原预览不可执行，用户重新核实；不能自动确认新预览 |
| 提交响应丢失 | 保留同一凭据，先查询结果；查不到也不等于没有提交 |

禁止推断退款到账时间、运费扣除数额、会员免费退货次数。只有检索或业务接口明确返回才能解释。
